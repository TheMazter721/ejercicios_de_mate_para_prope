# Plataforma de Práctica Matemática - Propedéutico Universitario

## Descripción
Esta plataforma web está diseñada para apoyar a los estudiantes del curso propedéutico en el fortalecimiento de sus habilidades matemáticas. El sitio genera ejercicios de forma dinámica, permitiendo una práctica ilimitada y autónoma.

## Temas Disponibles
El sitio incluirá los siguientes temas:
* **Aritmética:** Operaciones básicas, fracciones y jerarquía de operaciones.
* **Polinomios:** Operaciones, factorización y productos notables.
* **Ecuaciones:** Resolución de ecuaciones lineales y cuadráticas.
* **Sistemas de Ecuaciones:** Resolución de sistemas 2x2.

## Características Técnicas
* **Renderizado:** Uso de **MathML** para una visualización accesible y precisa de las fórmulas matemáticas.
* **Generación Dinámica:** Algoritmos en JavaScript para la creación aleatoria de ejercicios, evitando la repetición constante.

## Tecnologías utilizadas
* HTML5
* MathML
* Javascript
* Git & GitHub
